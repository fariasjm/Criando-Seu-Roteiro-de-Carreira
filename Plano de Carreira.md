## 💬 ROTEIRO DE ENTREVISTAS

**PERGUNTA 1:** O que é a diferença entre `let`, `var` e `const`?  
**COMO RESPONDER:**  
Explique que `var` tem escopo de função e pode ser redeclarada; `let` e `const` têm escopo de bloco, sendo `const` imutável. Dê exemplos práticos.

---

**PERGUNTA 2:** Como você organiza o CSS em um projeto grande?  
**COMO RESPONDER:**  
Fale sobre metodologias como BEM, componentização com CSS Modules ou Styled Components, e a importância de manter consistência e reuso.

---

**PERGUNTA 3:** O que é o Virtual DOM e como ele funciona no React?  
**COMO RESPONDER:**  
Explique que o React mantém uma cópia do DOM em memória, compara com o real (diffing) e atualiza apenas os nós que mudaram, melhorando performance.

---

**PERGUNTA 4:** Como você consumiria uma API em React?  
**COMO RESPONDER:**  
Use `useEffect` com `fetch` ou `axios`, trate estados de loading e erro, exiba os dados e limpe o efeito se necessário.

---

**PERGUNTA 5:** O que você faria para melhorar a performance de um site?  
**COMO RESPONDER:**  
Mencione lazy loading, uso de `useMemo`/`useCallback`, compressão de imagens, minificação de CSS/JS e boas práticas de acessibilidade.
